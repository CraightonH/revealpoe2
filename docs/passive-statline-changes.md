# Passive Stat-Line Corrections

Compares the **old** stat-text resolution (the pre-feature `scripts/graph/passives.js`,
which took `English[0]` unconditionally and ignored `index_handlers`) against the
**current** canonical resolver in `scripts/graph/passiveSource.js`. Two fixes
combine here:

1. **Entry selection (`pickEntry`)** — selects the translation entry whose
   `condition` range covers the stat's value (so a stored negative value uses the
   "reduced"/"less" entry, value-dependent templates resolve, plural forms apply).
2. **`index_handlers`** — transforms the stored value before substitution:
   `negate` (`-20` → `20% reduced`, not the double-negative `-20% reduced`),
   `milliseconds_to_seconds` (`6000` → `6 seconds`), `per_minute_to_per_second`,
   `divide_by_one_hundred`, `divide_by_ten_1dp_if_required`, `add_one`.

These were reviewed and **accepted** as intentional improvements (Global
Constraint #4 — byte-identical graph output — relaxed for these nodes by
decision). Node identity, slugs, edges, and all other props are unchanged; only
the `statLines` text differs. (The `+#` format sign — e.g. `+10 to Strength` —
is left unchanged for now; it's a separate, ambiguous axis.)
